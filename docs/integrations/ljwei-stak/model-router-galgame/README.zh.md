# Model Router + GALGame 文档

[English](README.md) | 中文

本目录预留给 Model Router + GALGame 集成的 fork 专属新增文档。插件契约和实现仍以 [`plugins/model-router-galgame`](../../../../plugins/model-router-galgame/README.zh.md) 为准。

不同用途应继续使用独立子目录：

- `guides/`：用户和管理员操作步骤；
- `research/`：路由数学模型、LiveBench 快照和可复现实验；
- `releases/`：按版本划分的安装与下载说明。

不要再把 fork 专属新页面放到上游 cookbook。已有 cookbook 页面作为 fork 已发布链接的兼容入口保留。
