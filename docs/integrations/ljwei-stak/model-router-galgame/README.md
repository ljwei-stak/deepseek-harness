# Model Router + GALGame documentation

English | [中文](README.zh.md)

This directory is reserved for new fork-owned documentation about the Model Router + GALGame integration. The plugin contract and implementation remain in [`plugins/model-router-galgame`](../../../../plugins/model-router-galgame/README.md).

Use child directories for separate concerns:

- `guides/` for user and administrator procedures;
- `research/` for the routing model, LiveBench snapshots, and reproducible experiments;
- `releases/` for version-specific installation and download notes.

Do not add new fork-only pages to the upstream cookbook. Existing cookbook pages remain compatibility entries for links already published by the fork.
