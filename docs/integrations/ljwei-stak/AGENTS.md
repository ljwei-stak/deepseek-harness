# Fork-specific documentation

English | [中文](AGENTS.zh.md)

This directory is the ownership boundary for documentation added by the `ljwei-stak/deepseek-harness` fork.

- Put new fork-only integration guides, release notes, migration notes, and research supplements below this directory.
- Keep each feature in its own child directory; do not add fork-only files to upstream-owned paths such as `docs/cookbook/` or the repository root.
- Keep source code and package contracts beside their owning plugin. Link to those documents instead of copying their content here.
- Add an English and Chinese pair for user-facing documents when both languages are required; keep generated catalogs and upstream documentation outside this directory.
- Treat existing documents outside this directory as compatibility entries. Do not move or rewrite them solely to enforce this policy.
