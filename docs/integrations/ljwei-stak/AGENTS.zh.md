# Fork 专属文档规则

[English](AGENTS.md) | 中文

本目录是 `ljwei-stak/deepseek-harness` fork 专属文档的归属边界。

- 新增的 fork 专属集成指南、发布说明、迁移说明和研究补充放在本目录下。
- 每项功能使用独立子目录；不要把 fork 专属文件添加到 `docs/cookbook/` 或仓库根目录等上游路径。
- 源码和插件契约放在所属插件旁边，本文档只建立链接，不复制实现细节。
- 面向用户的文档在需要时提供英文和中文配对；生成目录和上游文档不放在这里。
- 目录外的既有文档是兼容入口，不要仅为执行本规则而移动或重写。
